# Demo Guide

1. Install dependencies with pip install -r requirements.txt.
2. Run streamlit run app.py.
3. Select different virtual patients from the sidebar.
4. Show how historical state and current sensor state appear together.
5. Point to the current glucose trajectory and the 200 mg/dL event threshold.
6. Show the model's 2-hour probability and risk tier.
7. Explain that a real deployment would send the flag to a clinician rather than automatically changing treatment.

All patients and observations are synthetic.
